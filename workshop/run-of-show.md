# 90-minute run of show

| Time | Segment | Visible audience takeaway | Primary artifact |
|---|---|---|---|
| 0–7 | Reverse reveal | Start with the decision, not the scaffolding | Deployed app + health output |
| 7–15 | Context anatomy | Files beat giant prompts: instructions, skill, agent, tool | `workshop/workshop-manifest.json` |
| 15–25 | Source acquisition | MCP inspects/authorizes; CLI makes work repeatable | Prompt 01 |
| 25–36 | Data skill and join | A skill captures reusable judgment and guardrails | Prompts 02–03 |
| 36–45 | Airtable serving layer | OAuth and runtime secrets have different jobs | Prompt 04 |
| 45–56 | Visual brainstorming | Compare hierarchy before coding | Three All Companies options |
| 56–63 | Dashboard skill and handoff | A compact brief gives an agent a bounded lane | Prompt 05 |
| 63–73 | Inspect the build | Verify states, evidence, and responsive behavior | Prompt 06 + selected reference |
| 73–85 | Deploy and schedule | MCP configures; CLI uploads; cron refreshes | Prompt 07 |
| 85–90 | Proof and recap | Health, replay, and the context stack make it repeatable | Expected outputs + tags |

Final proof is immutable. At a segment boundary, move to the prepared artifact rather than borrowing from the final five minutes.
